# Cloud Computing Lab

## Experiments

### Experiment 1 - [Installing and opening Oracle Virtual Machine](Installing%20and%20opening%20Oracle%20Virtual%20Machine.docx)

Creating and configuring a new Ubuntu virtual machine for cloud computing practice.

### Experiment 2 - [Creating and preparing two Ubuntu Virtual Machines in VirtualBox](Creating%20and%20preparing%20two%20Ubuntu%20Virtual%20Machines%20in%20Virtualbox.docx)

Configure two virtual machine instances in VirtualBox to establish client-server communication and implement a basic TCP-base chat application between the two virtual machines.

### Experiment 3 - [Creation of Simple Network Topology and Visualization](Creation%20of%20Simple%20Network%20Topology%20and%20Visualization.docx)

To create a simple network topology using an open source network virtualization tool and verify communication between the virtual network nodes.

### Experiment 4 - [Software Defined Networking (SDN)](Assignment%204%20-%20SDN.docx)

Study and implement the fundamentals of Software Defined Networking using an open-source network virtualization tool.

### Experiment 5 - [Implementation of Various Scheduling Mechanisms Using an Open-Source Cloud Simulator](Assignment%205.docx)

Implement and evaluate various task scheduling mechanisms using an open-source cloud simulator.

### Experiment 6 - [Familiarization and Usage of Cloud Services Using AWS and Open-Source Cloud Tools](Assignment-6.docx)

Become familiar with cloud services provided by AWS and open-source cloud tools through practical usage.

### Experiment 7 - [Familiarization and Usage of Collaborative Applications (SaaS)](EXPERIMENT%207.docx)

Become familiar with collaborative applications delivered through the Software as a Service (SaaS) cloud model.

### Experiment 8 - [Implementing Applications using Google App Engine (PaaS)](EXPERIMENT%208.docx)

Implement and deploy applications using Google App Engine as a Platform as a Service (PaaS).

### Experiment 9 - [Develop MapReduce Application Using Hadoop Cluster Setup](EXPERIMENT%209-%20Develop%20MapReduce%20Application%20Using%20Hadoop%20Cluster%20Setup.docx)

Develop and execute a MapReduce application using a Hadoop cluster setup.
